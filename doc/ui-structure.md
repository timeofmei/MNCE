# 页面与导航

本文件记录 MVP 的初步信息架构。三个学习模式内部的按钮级流程和视觉设计仍待讨论。

## 一级页面

### 媒体库

- 作为应用默认首页。
- 顶部选择目标学习语言。
- 包含“单文件”和“文件夹系列”两个标签。
- 提供添加文件、添加文件夹和刷新系列入口。
- 展示媒体名称、时长和识别状态。
- 点击媒体进入详情页。

### 模型管理

- 按语言展示应用内置的 Whisper 模型。
- 展示模型名称、版本、大小和安装状态。
- 提供下载、取消、重试和删除操作。
- 展示模型来源和许可证信息。

### 设置

MVP 设置范围包括：

- Whisper 模型和应用数据存储位置
- DeepSeek API Key
- 自定义 OpenAI-compatible 服务配置
- 推理与 FFmpeg 基本信息
- 关于、GPLv3 和第三方许可证
- 缓存及应用数据清理

界面只提供中文，不设置界面语言切换项。

## 媒体详情页

- 展示文件基本信息和识别状态。
- 提供开始、取消、删除结果和重新识别操作。
- 识别完成后展示只读文本及时间轴。
- 提供影子跟读、逐句听写和全文背诵入口。
- 提供原始音频播放。

## 任务状态

识别任务不设置独立一级页面。在界面底部使用轻量任务区域展示当前任务、等待队列和失败状态。

## 学习页面

三个学习模式共用播放器、播放速度、音量和退出操作。模式专属区域和完整操作流程记录在 [学习模式](learning-modes.md) 中，并在后续讨论中确定。
