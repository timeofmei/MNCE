# 目标语言与内容空间

## 适用范围

本文记录贯穿媒体管理、模型、转写、分句、学习模式和任务系统的目标语言规则。这些规则不是 M2 的临时实现细节，后续里程碑都必须遵守。

## 可扩充语言目录

应用通过一个集中、只读的目标语言目录提供当前版本支持的语言。每个目录项至少包含稳定语言 ID、中文显示名称和是否为默认项；模型等后续能力通过语言 ID 与目录项关联。

MVP 当前支持的目标语言由 [产品范围](product-scope.md) 定义，但数据模型、界面和业务流程不得假设目录项数量固定。新增语言应通过扩充目录及对应资源完成，不应要求修改媒体表结构或复制一套业务流程。当前目录默认语言为英语。

稳定语言 ID 使用规范化的 BCP 47 语言标签，例如 `en`、`ja` 和 `zh-Hans`。目录负责提供规范形式；持久化、查询和内容关联均使用该形式，不使用中文显示名称作为标识。

## 全局语言上下文

- 目标语言选择器的位置由 [页面与导航](ui-structure.md) 定义，不属于单条媒体的编辑界面。
- 用户可以切换当前目标语言，应用的媒体库、模型、任务、详情和学习入口随之切换到对应内容空间。
- 首次启动使用目录指定的默认语言。用户切换后立即保存，并在后续启动时恢复；保存值不在当前目录中时回退到目录默认项。
- 语言切换只改变当前上下文，不迁移或修改已有内容。
- 异步任务在创建时必须保存自己的目标语言 ID。之后切换当前语言不得取消任务或改变结果归属；任务结果始终写入启动时绑定的语言空间。

## 内容归属与隔离

媒体、系列、转写、分句、学习内容和任务在创建时永久绑定一个目标语言 ID，之后不能修改语言归属。

不同语言空间不共享上述内容。同一原始音频可以分别加入多个语言空间，每个空间建立独立媒体记录及后续结果。媒体内容去重只在同一语言空间内生效。

应用级技术设置在语言空间之间共享，包括存储位置、API Key、界面偏好、播放器音量和其他不属于学习内容的设置。切换目标语言不复制、重置或覆盖这些设置。

## 实现约束

- UI 选择器从目标语言目录动态生成，不为具体语言编写条件分支。
- 持久化使用稳定语言 ID，不保存中文显示名称作为关联键。
- 数据库不得用只允许当前 MVP 语言的枚举或 `CHECK` 约束限制语言 ID。
- 领域服务必须显式接收语言上下文，不能依赖隐藏的全局默认值创建内容。
- 异步回调不得在完成时重新读取当前 UI 语言来决定结果归属。
- 查询、唯一约束和任务调度必须包含语言 ID，防止跨语言读取或复用内容。
- 自动测试必须使用可注入的语言目录，并验证增加第三种测试语言不需要修改 schema 或通用 UI 逻辑。
