# 学习模式

三个模式共用播放器、播放速度和退出操作。应用不提供音量控制；详细页面流程和控件布局尚待讨论。

## 通用逐句播放

- 学习内容按分句结果逐句播放。
- 每句播放前后插入短暂静音，帮助用户跟上播放节奏。
- 单句循环同样包含前后静音。
- 静音时长应可配置，具体默认值和范围待定。

## 影子跟读

- 按句播放或循环原始音频。
- 显示当前句文本。
- 支持调节播放速度和句间停顿。
- 用户可以录制自己的跟读并立即回放。
- 每句只保留当前会话最近一次录音，重新录制即替换。
- MVP 不做自动发音评分。

## 逐句听写

- 播放单句，用户输入听到的内容。
- 支持重复播放和慢速播放。
- 提交后与 Ground Truth 比较。
- 差异按字符级标记，不识别或依赖单词边界。
- 比较前可以进行基础规范化，包括大小写、常见标点、空格以及全角/半角差异。
- 用户可以查看本句答案，但结果不沉淀为学习进度或长期错句记录。

## 全文背诵

- 背诵期间不显示原文，也不提供文字提示或文本输入。
- 用户录制完整背诵内容。
- 结束录音后才启动本地 Whisper 识别，允许用户等待处理完成。
- 识别完成后展示原文、背诵识别文本以及字符级错误位置。
- 不识别或依赖单词边界。
- 用户可以回放本次背诵录音。
- MVP 不做发音评分。

## 录音生命周期

- 练习录音属于当前会话的临时数据。
- 开始新的对应录音时替换上一次录音。
- 退出学习页面后清理临时录音。
- 应用下次启动时清理异常退出遗留的临时录音。
- 当前方案允许提供“另存为音频”，由用户主动保存到指定位置；该文件不进入 MNCE 媒体库。

## 错误反馈

- 听写和背诵都使用字符级差异。
- 不建立单词边界，也不提供单词级语义判断。
- 英语和日语的具体规范化规则、替换/遗漏/新增字符的视觉表现仍待确定。
